# 🎬 app-movies

**4BA Cinematic Gold - Movie Catalog & Filtering Module**

## Purpose
Manages and displays a comprehensive catalog of movies with filtering, search, and categorization features.

## Features
- Movie catalog with metadata
- Genre-based filtering
- Search functionality
- Quality/resolution selection
- Release date sorting

## Integration
This module is part of the **4BA Cinematic Gold** ecosystem and is managed through the **app-shell** gateway.

**Gateway URL:** https://ma-tv.github.io/app-shell/
**Module Route:** `movies`
